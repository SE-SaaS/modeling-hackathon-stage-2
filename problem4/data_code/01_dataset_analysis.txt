==============================================================================
6. ROI CROP BAND + INPUT TENSOR FOR THE LIGHTS MODEL
==============================================================================
Crop = full image width x band [y0,y1] of the height, then FIT (aspect-preserving,
letterbox) into the input tensor TWxTH. scale = min(TW/crop_w, TH/crop_h).
Cropping vertically does NOT raise resolution on its own for these wide frames --
width is the limiting dimension. It only helps if the tensor is also wide and short,
so the same TW covers fewer source pixels of height. What actually buys resolution
is a larger TW, and the crop is what makes a large TW affordable.
'cov' = fraction of light boxes fully inside the band.
'px' = median light width in tensor pixels. 'MPix' = tensor area, the cost proxy.
