 Run everything from:  D:\My Projects\modeling-hackathon-stage-2

#---------- upload the dataset ----------
# ~5200 files / 2.4 GB, uploaded as a folder. Takes a few minutes.
# The remote layout must end up as:  /data/dataset_release/{train,val}/{images,labels}
modal volume put tiny-data "C:\Users\mamou\Downloads\too-small-to-handle\dataset_release\dataset_release" /dataset_release

# (sanity) confirm the layout before launching anything
modal volume ls tiny-data /
modal volume ls tiny-data /dataset_release

#---------- regenerate experiment folders (only after editing _make_experiments.py) ----------
# Rewrites every train.py from the template. Existing config.yaml files are kept.
python problem4/training_scripts/_make_experiments.py


==========================================================================
 RUN THE EXPERIMENTS
 All 9 are independent — launch them in separate terminals, they run in
 parallel. Each builds its own dataset on first use and caches it on
 /runs/_datasets/<cache_key>, so runs sharing a cache_key reuse the build.
 Launch ONE of each cache_key first if you want to avoid duplicate builds;
 otherwise just fire them all, the cost is a couple of minutes each.
==========================================================================

# --- LIGHTS: input size sweep (the score lives here) ---
