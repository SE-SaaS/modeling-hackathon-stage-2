==========================================================================
 STEP 2 — RUN THE EXPERIMENTS
 All 13 are independent; launch them in separate terminals and they run in
 parallel. Each builds its dataset on first use and caches it at
 /runs/_datasets/<cache_key>, so runs sharing a cache_key reuse the build.
 Launch ONE of each cache_key first to avoid duplicate builds; otherwise
 just fire them all, the cost is a couple of minutes each.

 Splitting across workspaces: every terminal must set MODAL_CONFIG_PATH to
 the workspace it is launching into, and that workspace must already have
 completed STEP 1. Runs in different workspaces share nothing — including
 the dataset cache, which each one rebuilds.
==========================================================================

# Every line below is copy-paste runnable as-is.

# Give them ~3 min, then start the rest, which reuse those builds.

==========================================================================
 STEP 3 — RESULTS  (mostly automatic)

 Each `modal run .../train.py` above ALREADY downloads its own results into
 problem4/training_scripts/<exp>/results/ when it finishes — including when
 it crashes, so the logs and last.pt come back either way. Normally there is
 nothing to do here.

 Re-running the same command is always safe. It looks at what exists locally
 and on the volume and picks one of:
     local complete   -> does nothing
     remote complete  -> downloads, does not retrain
     remote partial   -> resumes training from last.pt
     nothing anywhere -> trains from scratch
==========================================================================

# --- per-experiment flags (all optional) ---
modal run problem4/training_scripts/lights_t768/train.py --fetch-only    # download, never train
modal run problem4/training_scripts/lights_t768/train.py --force         # retrain from scratch
modal run problem4/training_scripts/lights_t768/train.py --weights-only  # skip plots/CSVs

# --- all 13 at once: status table + pull anything missing ---
python problem4/training_scripts/_fetch_all.py
python problem4/training_scripts/_fetch_all.py --status         # report only
python problem4/training_scripts/_fetch_all.py --weights-only
